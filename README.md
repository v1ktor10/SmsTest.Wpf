# SmsTest WPF — редактор переменных среды

Десктопное приложение на WPF (.NET 8) для просмотра и редактирования
переменных среды Windows в табличном виде.

---

## Переменные среды

Возможно под "неким набор переменных среды" имелся ввиду обычный .env-файл,
но здесь выбран вариант работы с переменными среды самой Windows. Требованию
"все записанные переменные и их значения должны быть доступны другим
приложениям и сохраняться даже после перезапуска ОС" они отвечают.

---

## Как это работает

При запуске приложение читает список имён переменных из `appsettings.json`
и отображает их в таблице вместе с текущими значениями из реестра Windows
и пользовательскими комментариями.

Изменения сохраняются автоматически — сразу после того как пользователь
покидает ячейку.

Комментарии хранятся отдельно в JSON-файле рядом с исполняемым файлом
(имя файла настраивается).

---

## Конфигурация — appsettings.json

```json
{
  "Serilog": { ... },
  "App": {
    "EnvironmentVariableNames": [
      "SMS_API_URL",
      "SMS_API_KEY",
      "SMS_DATABASE_HOST",
      "SMS_DATABASE_PORT",
      "SMS_LOG_LEVEL"
    ],
    "EnvironmentVariableTarget": "User",
    "CommentsFileName": "comments.json",
    "LogDirectory": "logs",
    "RetainedLogFileCount": 30
  }
}
```

| Параметр | Описание |
|---|---|
| `EnvironmentVariableNames` | Список переменных, отображаемых в таблице |
| `EnvironmentVariableTarget` | `User` — переменные текущего пользователя (по умолчанию); `Machine` — системные, требуют прав администратора |
| `CommentsFileName` | Имя файла для хранения комментариев |
